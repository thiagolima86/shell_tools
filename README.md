## Mp42gif
### Use

```bash
bash <(curl -s https://raw.githubusercontent.com/thiagolima86/shell_tools/main/mp42gif) <path_of_file.mp4>
```

Change the default width

```bash
bash <(curl -s https://raw.githubusercontent.com/thiagolima86/shell_tools/main/mp42gif) <path_of_file.mp4> --width800
```
