# shell_tools
Minhas ferramentas shell script

## Install Workspace
VS Code + extensões, Postman, Docker, git, vim, guake, pasta `~/workspace`, git config e chave SSH.

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/thiagolima86/shell_tools/main/Installers/workspace-install.sh)
```

## Mp42gif
### Use

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/thiagolima86/shell_tools/main/mp42gif) <path_of_file.mp4>
```

Change the default width

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/thiagolima86/shell_tools/main/mp42gif) <path_of_file.mp4> --width800
```
